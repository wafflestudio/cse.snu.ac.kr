04. 행동 강조와 입력

방향 확정 · 사용처 적용 전

주요 실행은 짙은 중립색

추가·저장·게시·예약처럼 작업을 완료하는 행동은 짙은 중립색을 기본으로 한다. 주황의 그래픽·선택 역할은 유지한다.

위험 행동, 어두운 배경 위 버튼, 모든 호버·비활성 상태와 컴포넌트 공통 규칙은 후속 검토한다.

실제 적용 확인: 공지 제목과 예약 입력/textarea 1280·390px, 보조 버튼 기본·호버. 로컬 프로덕션 빌드의 표본 확인이며 전체 회귀는 아니다.

모바일 예약창에서 가로 넘침과 초점 일부 잘림을 관찰했다. 별도 배치 검토 항목으로 남겼다.

06. 지원 범위와 아직 정하지 않은 것

지원 방향 확정 · DS-003

공개 기능은 모바일까지

탐색·읽기·검색·일반 예약은 모바일과 데스크톱을 지원한다. 행정실 편집·관리는 데스크톱 중심으로 설계한다.

모바일 편집 최적화는 v1 필수 조건에서 제외한다. 최소 지원 폭·배치 전환값은 아직 정하지 않았다.

후속 기반 규칙

타이포 위계·아이콘·레이아웃

글자 크기·굵기·행간·문단 간격, 아이콘과 조작 영역, 반응형 배치와 간격, 모서리·크기·그림자, 컴포넌트 전체 규칙은 남아 있다.

현재 앱 값이나 이전 tmp 브랜치의 규칙을 확정값으로 가져오지 않는다.
