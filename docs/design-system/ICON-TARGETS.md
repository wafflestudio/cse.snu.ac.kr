# 아이콘 클릭 영역 — DS-018 적용 완료

[누적 DS](index.html) · [실제 비교](icon-targets.html) · [진행 계획](PLAN.md)

## 먼저, 확정한 내용

DS-017 헤더 검색의 기본 #737373 → 호버 #404040을 적용했고 한국어·영어 승인 견본과 일치했다.
DS-016에 따라 기존 그림·선 굵기·배치는 유지한다. 작은 그림이라고 모두 키우지 않는다.

## 수정 전 문제와 변경 이유

한·영 1280·390px에서 검색·모바일 메뉴·닫기 22개 상태를 실측했다.
헤더 검색, 세미나 검색, 모바일 검색 실행은 버튼 영역이 작고 바로 옆 입력칸에 붙어 있다.
24px 지름의 간격 확인 원을 버튼 중앙에 두면 입력칸과 겹친다. 정밀하게 누르지 못하면 검색 대신 입력칸에 닿을 수 있는 배치다.
이는 사용자 오작동 관찰 결과가 아니라 실제 영역과 인접 간격에서 확인한 문제다.

[WCAG 2.2의 2.5.8(AA)](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html)은 기본적으로 최소 24×24 CSS px의 타깃을 요구하지만 간격·동등한 다른 조작 등 예외를 허용한다.
따라서 24px보다 작다는 사실만으로 미달로 단정하지 않는다. 이번 세 검색 실행에는 바로 붙은 입력칸 때문에 간격 예외를 적용할 수 없으며, 확인한 화면에서 같은 검색을 실행하는 다른 충분한 크기의 포인터 조작도 없다.
입력칸에서 Enter로 실행할 수 있다는 점은 작은 포인터 타깃의 해결로 대신하지 않는다.
24px는 그림 크기나 모든 버튼의 새 디자인 크기가 아니다. 44px 확대도 이번 제안에 포함하지 않는다.

[실측 기록](icon-target-audit/measurements.json). 인접 타깃의 경계와 중앙 간 거리로 조사했고 실제 포인터의 최상단 요소도 확인해 뒤에 가려진 요소를 제외했다.
표의 간격 판정은 해당 화면·폭의 표본이다. 모든 사용처·동적 상태가 적합하다는 뜻은 아니다.
모든 표본에서 키보드 초점 도달과 기존 브라우저 초점 표시를 확인했다. 초점의 모든 배경별 대비·가림은 4단계에서 추가 확인한다.

## 확정·적용 — 세 검색 실행의 투명한 클릭 영역만 넓힌다

- 헤더 검색은 24×30, 세미나·모바일 검색 실행은 24×24로 한다.
- 아이콘 그림의 크기·선·색·위치와 바 전체 크기는 유지한다. 모바일 전용 돋보기를 Lucide로 교체하지 않는다.
- 입력칸과 버튼 영역을 재배분하므로 입력칸의 실제 폭은 헤더·세미나 2px, 모바일 2.5px 줄어든다. 입력 텍스트 시작점은 같다.
- 기존 호버 상태는 넓어진 버튼 전체에서 반응한다. 모바일 전용 SVG의 고정 밝은 색은 그대로다. 키보드 초점 경계도 새 버튼 영역을 따른다. 입력에 새 외곽선을 추가하지 않는다.
- 공용 Button API·다른 quiet 버튼·검색 로직은 이번 변경 범위가 아니다.

승인 전 비교는 앱 DOM에 스타일을 임시 지정해 준비했다. **DS-018로 앱 소스에 적용·표본 확인을 마쳤다.**
[실제 적용 기록](icon-target-implementation/measurements.json)의 한·영 8장면이 승인 견본과 일치했다. 넓어진 가장자리의 버튼 판정·호버·Tab 초점도 확인했다.
긴 입력문을 넣어도 바·버튼 크기를 유지하고 입력칸 안에서 가로 스크롤되며, 입력에 새 외곽선은 추가되지 않았다. 검색 제출은 하지 않았다.
한·영의 헤더 2장면, 세미나 두 폭 4장면, 모바일 실행 2장면에서 짧은 입력 문구를 넣은 검색 바 이미지가 전후 바이트까지 일치했다.
그림·바의 좌표와 크기가 같고 넓어진 버튼의 네 모서리 안쪽이 실제 버튼으로 판정되는 것도 확인했다.
[비교 측정 기록](icon-target-comparison/measurements.json). 긴 입력문에서 가로 스크롤이 시작하는 지점은 줄어든 입력 폭의 영향을 받을 수 있다. 검색 제출은 하지 않았다.
문서의 파란 면은 눌리는 영역을 설명하는 표시로, 앱 디자인에 추가하는 색·테두리가 아니다.

## 남은 범위

태그 삭제·첨부·페이지 이동·캐러셀 등 나머지 아이콘 사용처는 후속 조사다. 전체 아이콘 검토를 완료로 표시하지 않는다.
Dialog 닫기 이름 누락은 PLAN Q-12에 기록하고 지금 로직·접근성 속성 변경으로 범위를 넓히지 않는다.
모바일 검색 전용 SVG의 고정 밝은 색도 이번 클릭 영역 안에서는 유지한다. 모바일 호버 피드백·공통 상태 조합은 4단계와 연결한다.

## 결정 상태

DS-018로 **세 검색 실행의 클릭 영역 확대를 적용·확인했다.**
나머지 작은 닫기·열기 아이콘을 함께 키우는 결정은 아니다.

## 문서 확인

1280·390px에서 누적 DS·호버 적용 문서·클릭 영역 비교 문서를 확인했다. 페이지 가로 넘침이 없고, 언어·사용처·영역 표시 전환에 따라 32개 비교 이미지가 정상 로딩됐다. 내부 링크도 확인했다.
