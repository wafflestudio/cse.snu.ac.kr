# DS-040 — 긴 페이지 제목의 크기 유지와 줄바꿈

[실제 적용 견본](long-title.html) · [현재 DS](index.html) · [통합 검증](INTEGRATION.md)

**LT-Q1 승인 · DS-040 적용·대표 검증 완료.** 참가자 한영 320/390/1280px의 실제 이미지 6장이 승인 견본과 바이트까지 일치했다. 다른 제목 4개 경로의 한영 세 폭, 24개 상태도 기존 스타일과 이미지가 동일했다. [실제 측정 30개 기록](long-title-implementation/measurements.json).

## 확인한 문제와 변경 이유

5단계 전체 읽기 검증에서 10-10 프로젝트 참가자 페이지의 기존 가로 넘침을 확인했다. 한영 320/390px에서 문서 폭이 412px이었다. `Participants(Professors)` 제목과 오른쪽 장식용 100px 공간을 합친 최소 폭이 화면보다 컸다. 이번 DS 변경 전 기준 이미지에도 있던 문제다.

공개 화면은 320px까지 검증하기로 한 DS-028에 따라 실제 읽기 배치를 보완했다. 글자 크기를 바꾸지 않고 해결해 DS-016의 기존 디자인 유지 기준을 따른다.

## 승인 규칙과 실제 적용 범위

- `Participants`와 `(Professors)` 사이에 줄바꿈 가능 지점을 둔다. 문구·굵기·색과 기존 글자 크기(작은 화면 24px, 데스크톱 32px)를 유지한다.
- **괄호 앞 줄바꿈 지점이 있는 제목에만** 제목 상자 폭 제한을 적용한다. 공용 제목 전체의 폭을 일괄 제한하지 않는다.
- 오른쪽 장식 공간 100px를 유지해 글자와 대각선이 겹치지 않게 한다. 충분히 넓으면 기존 한 줄이다.
- 실제 320/390px는 두 줄이며 제목 높이 약57.59px, 문서 폭은 각각320/390px다. 작은 화면의 제목 높이는 기존보다 약29px 늘어난다. 1280px는 기존 한 줄·32px를 유지하며 승인 견본과 일치한다.
- 인사말·공지 목록·학부 교과목·연구 분야의 한영 320/390/1280px 총24개 상태는 기존 스타일과 동일했다. 이는 모든 페이지의 넘침 해결이나 전체 회귀 완료를 뜻하지 않는다.

## 유지한 범위와 다음 검토

개인정보 표는 정지 캡처에서 오른쪽 열이 안 보여 별도로 확인했다. 기존 CSS가 표 영역만 가로 스크롤하도록 되어 있고, 320px에서는416px, 390px에서는346px만큼 실제 가로 휠 이동해 마지막 ‘보유·이용기간’ 열을 읽을 수 있었다. 기존 표와 명시된15·17·19px 글자 크기·문구를 유지한다. 에디터 내부나 공유 본문 스타일은 추가 수정하지 않았다.

영어 교과목 320px는 기존과 동일하게 문서 폭364px이며 긴 경로 안내(breadcrumb)의 넘침이 남는다. DS-040으로 해결했다고 표시하지 않는다. 다음 별도 검토 묶음이며 비교 자료는 아직 준비 중이다. 남은 접근성 적용·검증은 마지막에 진행한다.
