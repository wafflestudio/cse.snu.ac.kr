## DS-035 — 색만 적용

사용자 “2에서는 색만 바꾸자. 문구 추가하니 verbose해보여”. 빈 검색 결과의 문장색만 neutral-300에서 neutral-500(#737373)으로 변경했다. 기존 한국어 ‘검색 결과가 존재하지 않습니다’, 영어 ‘No search results found.’와16px 크기·굵기·정렬·돋보기 그림은 유지했다. 추가 안내 문구는 채택하지 않았다.

한영320/1280px 실제 빈 결과에서 문구·색·크기를 확인했다. [측정](card-empty-implementation/simple-measurements.json).

## 메인 카드 초점 — 마지막 단계로 보류

사용자는 안쪽 A/B 대신 바깥 초점선을 자르지 않는 방법을 요청했다. 잘림 경계에 여유를 확보하는 방식을 시험했으나 모바일 키보드 이동의 잘림이 남았다. 이후 접근성 작업 전체를 나머지 DS 완료 뒤로 미루기로 했다. 작업 중이던 메인 카드·인물 사진 초점 변경은 되돌렸으며 기존 캐러셀 배치를 유지한다. 이전 A/B는 확정 규칙이 아니다.

이미 완료한 초점 적용은 유지한다. 다음 작업은 행동·처리 중 문구와 남은 컴포넌트 형태·상태다.
