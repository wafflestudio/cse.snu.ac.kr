2026-09-24. **CE-Q1·CE-Q2는 미확정·앱 미적용**이다. DS-033·034 이미지 안내창, DS-020 목록 초점과 DS-027 교과목 오류 추가 연결은 적용·대표 검증 완료했다.

## CE-Q1 메인 새 소식 카드

캐러셀의 overflow-hidden에 바깥 초점선이 잘린다. 단순 안쪽 outline도 위에 그려지는 이미지에 가린다. 카드 전체가 한 링크이므로 사진과 글을 포함한 조작 영역을 식별할 방법이 필요하다. 카드 크기·사진·글자·기존 그림자와 캐러셀 동작은 유지한다.

| 안 | 표시 | 이유·한계 |
| --- | --- | --- |
| A 추천 | 카드 안쪽에 흰2px + 짙은2px 선, 사진보다 위층에 표시 | 전체 클릭 영역을 보여주고 밝고 어두운 사진 배경을 함께 고려. 두 겹이라 초점 표현은 B보다 강함 |
| B | 사진 아래 글 영역에만 짙은2px 선 | 사진을 건드리지 않고 표시를 단순하게 유지. 실제 클릭 영역 전체를 둘러싸지는 않음 |

둘 다 키보드 초점 때만 나타난다. 일반 상태·호버·레이아웃은 바꾸지 않는다. A는 가장자리에서2px를 띄우고 흰선2px·짙은선2px 순서로 놓는다. B는 글 영역을 둘러싼다. 이미 승인한 ImageModal 두 버튼의 안쪽 표시를 자동으로 모든 사진 카드에 확대하지 않고 이 사용처를 별도로 비교한다.

비교는 실제 로컬 메인 카드에 DOM 테두리 레이어를 대입했다. 밝음/어두움은 사진 대비를 살펴보기 위한 시험용 바탕이며 실제 사진은 아니다. 승인 후 모바일 가로 스크롤·데스크톱 캐러셀과 실제 초점에서 레이어·잘림·강제 색상 모드를 확인한다. 모든 사진의 적합성을 선언하지 않는다.

## CE-Q2 빈 검색 결과

현재 ‘검색 결과가 존재하지 않습니다’는16px/neutral-300이다. 흰 바탕에서 결과 상태를 전달하는 주된 문장이 경계·장식에 쓰는 밝은 색으로 표시된다. 큰 돋보기 그림과 문장의 역할을 구분할 필요가 있다.

**추천:** 문장은 기존 보조 글자색neutral-500(#737373)으로 바꾸고 다음처럼 안내한다.

- 한국어: ‘검색 결과가 없습니다. 검색어를 바꿔 보세요.’
- 영어: ‘No results found. Try a different search term.’

16px 크기·굵기와 돋보기 그림은 유지한다. 좁은 화면에서는 문장을 가운데 정렬로 줄바꿈한다. 안내 색과 읽기 역할을 연결하고, 실제로 할 수 있는 검색어 변경을 제안한다. 검색 실패·한 글자 검색 안내와 혼동하지 않으며 필터·검색 동작은 변경하지 않는다. 없는 재시도 기능을 추가하지 않는다.
