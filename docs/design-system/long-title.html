LT-Q1 · 긴 제목은 크기를 유지하고 줄바꿈할까?

먼저 · 확정 DS와 적용 결과

예약은 단건·반복 모두 ‘취소’로 표현하고 반대 행동은 ‘예약 유지’로 맞췄다. 작은 확인창은90vw·최대512px, 버튼 글자는 유지하고 버튼 단위로 줄바꿈한다. 실제 적용 견본.

이번 작성·편집·삭제·예약·언어/보안 회귀79개는 통과했다. 전체 읽기140개의 이미지 차이는 별도 분류했고, 추가16장면에서 새로운 겹침·잘림은 없었다. 전체 DS 완료는 아니며 접근성 후속은 마지막이다.

문제와 추천 이유

참가자 화면은 기존에도320/390px 화면에서 문서가412px까지 넓어진다. 긴 제목과 장식용 여백이 원인이다.

추천:24px 글자와 그래픽을 유지하고, 괄호 앞에서 줄바꿈. 화면 폭 안에 제목을 두면서 기존 크기와 문구를 보존한다. 작은 화면의 제목 높이는약29px 늘어난다. 제목을 작게 만드는 예외는 추가하지 않는다.

공개320px 지원(DS-028)과 명확한 문제만 변경하는 원칙(DS-016)에 따른 제안이다. 현재는 브라우저 비교 견본이며 앱 코드에 적용하지 않았다.

1280px에서는 현재 한 줄 그대로이며 현재/제안 캡처가 같다. 데스크톱 견본.

확인 완료 · 개인정보 표는 기존 가로 스크롤 유지

오른쪽이 안 보이는 정지 이미지와 달리, 실제로 표 안에서 가로 스크롤해 모든 열을 읽을 수 있었다. 이 화면은 새로 수정하지 않는다.
