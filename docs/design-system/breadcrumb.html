BR-Q1 · 긴 경로 표시도 줄바꿈할까?

확정 DS · 실제 적용 완료

DS-040: 참가자 제목은24px와 그래픽을 유지하고 괄호 앞에서 줄바꿈하도록 적용했다. 한영3개 폭6장이 승인 견본과 일치했고, 다른 제목24개 장면은 기존과 같았다.

적용 결과와 승인 기록 · 누적 통합 검증.

새로 확인한 문제와 추천 이유

기존 경로 표시가 긴 경우, 작은 화면에서 오른쪽으로 넘친다. 유사8경로의 한영320/390px,32상태 중13상태에서 발생했다.

추천: 구분 화살표와 다음 이름을 묶어 줄바꿈. 긴 항목 안에서는 단어 단위로 줄바꿈하고, 글자 크기·문구·그래픽·이동 대상은 유지한다. 내용 생략이나 글자 축소 없이 화면 안에 담는 방식이다.

제안에서는32상태 모두 문서 가로 넘침이 없었다. 대신 경로와 제목의 줄 수, 상단 영역 높이는 늘어날 수 있다. 아래 교양 과목 이수규정은 제목도2줄에서3줄이 된다.

아직 앱에 적용하지 않은 DOM 비교다. 기존 에디터·주요 로직이나 초점 처리는 이 제안에 포함하지 않는다.
