# BR-Q1 — 작은 화면의 긴 경로 표시

[현재/제안 견본](breadcrumb.html) · [DS-040 실제 적용](long-title.html) · [계획](PLAN.md)

## 현재 문제와 변경 이유

DS-040을 다른 제목 사용처와 대조하면서 영어 교과목320px의 기존 가로 넘침을 확인했다. 경로 표시(breadcrumb)가 한 줄 flex이며 항목 고유 폭을 유지하고, 오른쪽 그래픽도 같은 행을 사용한다. 제목 상자 폭만 일괄 줄이면 경로가 왼쪽으로 밀려 잘리므로 그렇게 적용하지 않았다. DS-040은 괄호 줄바꿈 지점이 있는 제목으로 제한해 다른24장면을 기존과 동일하게 유지했다.

유사한8개 경로를 한영320/390px에서 조사했다.32상태 중13상태에서 문서 폭이 화면보다 컸다. 공개 최소 폭320px(DS-028)에서 가로 이동 없이 경로와 제목을 읽을 수 있도록 배치를 보완할 이유가 있다. 새 접근성/키보드 작업이 아니라 일반 화면 배치의 문제다.

## BR-Q1 제안 — 단계 단위 줄바꿈, 긴 항목은 단어 단위

- 제목 영역을 화면의 기존 좌우20px 안에 둔다.
- 경로의 구분 화살표를 다음 이름과 묶는다. `[Academics] [› Undergraduate] [› Courses]` 단위로 다음 줄로 내려가 화살표만 한 줄을 차지하지 않게 한다.
- 한 항목이 길면 그 안에서도 공백을 기준으로 줄바꿈한다. 글자 크기·문구·기존 이동 대상은 유지한다.
- 장식은 같은 행 오른쪽의 별도 공간에 유지한다. 제목의 기존 오른쪽100px 공간을 기준으로 장식 영역도100px를 확보하고 경로 줄 사이4px를 둔 비교다. 새 토큰을 추가하는 제안은 아니다.
- 경로가 여러 줄이면 장식은 기존 중앙 정렬을 유지한다. 제목도 화면 안에서 기존24px로 줄바꿈한다. 데스크톱은 기존32px·한 줄/기존 배치를 유지한다.
- 전체 영역 높이가 늘 수 있다. 영어 교양 과목 이수규정320px는 제목 자체도 기존2줄에서3줄이 된다. 크기를 줄이거나 내용을 생략하지 않는 대가다.

**앱에는 미적용이다.** 실제 페이지를 연 뒤 DOM에서만 스타일과 경로 항목 묶음을 바꾼 비교다. 32개 현재/제안64기록을 확인했으며 제안에서 문서 가로 넘침은 없었다. 이는8개 경로 표본이며 모든 제목·기기 검증 완료가 아니다. 확정하면 공용 사용처를 추가 대조한다.

## 결정할 사항

BR-Q1: 위 의미 단위 줄바꿈안을 공용 경로·제목 배치에 적용할까? 추천은 적용이다. 문구와 크기를 유지하고 작은 화면의 넘침을 해결하지만, 경로/제목의 줄 수와 상단 영역 높이는 늘어날 수 있다.
