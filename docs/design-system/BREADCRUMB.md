# DS-041 — 긴 경로의 단계별 줄바꿈과 왼쪽 정렬

[왼쪽 정렬 실제 적용](breadcrumb.html) · [DS-040 실제 적용](long-title.html) · [계획](PLAN.md)

**BR-Q1 사용자 정렬 선택 반영 · DS-041 적용·대표 검증 완료.** 사용자가 줄바꿈한 텍스트를 중앙 대신 왼쪽에 정렬하도록 지시했다. 실제 8개 경로의 한영320/390/1280px 총48개 상태에서 문서 가로 넘침이 없고 경로명은 모두 왼쪽 정렬임을 확인했다. 영어 대표6장도 왼쪽 정렬 견본과 바이트까지 일치했다. [실제 측정](breadcrumb-implementation/measurements.json).

## 확인한 문제와 변경 이유

DS-040을 다른 제목 사용처와 대조하면서 영어 교과목320px의 기존 가로 넘침을 확인했다. 경로 표시(breadcrumb)가 한 줄 flex이며 항목 고유 폭을 유지하고, 오른쪽 그래픽도 같은 행을 사용한다. 제목 상자 폭만 일괄 줄이면 경로가 왼쪽으로 밀려 잘리므로 그렇게 적용하지 않았다. DS-040은 괄호 줄바꿈 지점이 있는 제목으로 제한해 다른24장면을 기존과 동일하게 유지했다.

유사8개 경로의 한영320/390px 총32상태 중13상태에서 기존 문서 폭이 화면보다 컸다. 공개 최소 검증 폭320px(DS-028)에서 경로와 제목을 가로 이동 없이 읽을 수 있도록 배치를 보완한다. 새 키보드 작업이 아닌 일반 화면 배치 변경이다.

## DS-041 선택한 원칙

- 제목 영역은 기존 좌우20px 안에 둔다.
- 구분 화살표를 다음 이름과 묶어 `[Academics] [› Undergraduate] [› Courses]` 단계 단위로 줄바꿈한다. 화살표만 따로 한 줄에 남기지 않는다.
- **줄바꿈한 텍스트와 경로 항목은 왼쪽에 정렬한다.** 긴 항목 안에서는 공백을 기준으로 줄바꿈하며 중앙 정렬로 되돌리지 않는다.
- 글자 크기·문구·색·링크의 이동 의도를 유지한다. 작은 화면 제목24px와 데스크톱32px를 보존하고 내용 생략이나 축소를 추가하지 않는다.
- 기존 그래픽과 오른쪽100px 공간을 유지한다. 경로 줄 사이4px를 두며 새 토큰을 만들지 않는다. 텍스트의 왼쪽 정렬 선택을 그래픽 삭제·크기 변경으로 확대하지 않는다.
- 경로와 제목의 줄 수에 따라 상단 높이는 늘 수 있다. 공간이 충분하면 한 줄을 유지한다.

## BR-Q1 제안 — 단계 단위 줄바꿈, 긴 항목은 단어 단위

- 제목 영역을 화면의 기존 좌우20px 안에 둔다.
- 경로의 구분 화살표를 다음 이름과 묶는다. `[Academics] [› Undergraduate] [› Courses]` 단위로 다음 줄로 내려가 화살표만 한 줄을 차지하지 않게 한다.
- 한 항목이 길면 그 안에서도 공백을 기준으로 줄바꿈한다. 글자 크기·문구·기존 이동 대상은 유지한다.
- 장식은 같은 행 오른쪽의 별도 공간에 유지한다. 제목의 기존 오른쪽100px 공간을 기준으로 장식 영역도100px를 확보하고 경로 줄 사이4px를 둔 비교다. 새 토큰을 추가하는 제안은 아니다.
- 경로가 여러 줄이면 장식은 기존 중앙 정렬을 유지한다. 제목도 화면 안에서 기존24px로 줄바꿈한다. 데스크톱은 기존32px·한 줄/기존 배치를 유지한다.
- 전체 영역 높이가 늘 수 있다. 영어 교양 과목 이수규정320px는 제목 자체도 기존2줄에서3줄이 된다. 크기를 줄이거나 내용을 생략하지 않는 대가다.
