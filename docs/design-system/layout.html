값·역할·실측 범위와 다음 조사

왜 푸터의 줄바꿈을 바꿀까?

현재 긴 영어 링크가 자기 열을 벗어나 화면 밖으로 나간다. 링크 끝을 읽으려면 페이지를 가로로 움직여야 한다.

추천: 기존 모바일 범위에서 긴 링크가 열 안에서 단어 단위로 줄바꿈되도록 한다. 열 폭·그룹 순서·간격·글자·색은 유지한다.

대신 영어 항목 일부가 2~3줄이 되고 푸터가 세로로 길어진다. 390px 영어 표본은 약 94px 높아진다. 한국어와 1280px 데스크톱 견본은 전후 동일하다. 640~1199px의 페이지 최소 폭 문제는 이 변경으로 해결되지 않는다.

실제 푸터에서 비교

기존 · 한 줄 고정

추천 · 열 안에서 줄바꿈

실제 앱에서 모바일 링크의 white-space만 임시 변경했다. 기존 이미지는 화면 안에서 보이는 범위이므로 오른쪽 링크 끝이 잘려 보인다. 넓은 이미지는 문서 폭에 맞춰 축소한다. 앱 소스는 아직 미변경이다. 한·영 20개 상태 측정.

모바일 푸터의 긴 링크가 기존 열 안에서 자연스럽게 줄바꿈되도록 할까?
