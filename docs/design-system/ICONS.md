[현재 DS](index.html) · [헤더 검색 비교](search-icon.html) · [진행 현황](PLAN.md)

3-4를 시작했다. 기존 형태·크기·선 굵기를 기본으로 유지하고, 같은 역할·상태에서 식별 또는 조작 문제가 있는지 확인한다.

## I-Q1 — DS-017 적용 완료: 헤더 검색 아이콘의 호버

**수정 전 문제:** 밝은 #e5e5e5 검색 바 위의 돋보기가 기본 #737373에서 호버 시 흰색으로 바뀐다.
아이콘만으로 검색 실행을 표시하므로, 마우스를 올렸을 때 식별에 필요한 그림이 희미해진다.
한국어·영어 1280px의 실제 앱에서 기본·호버를 확인했다. 공용 quiet의 흰색 호버가 이 밝은 바탕에서도 적용되는 상황이다.

| 상태 | 아이콘 / 배경 | 대비 |
| --- | --- | --- |
| 기존 기본 | #737373 / #e5e5e5 | 약 3.76:1 |
| 기존 호버 | #ffffff / #e5e5e5 | 약 1.26:1 |
| DS-017 적용 호버 | #404040 / #e5e5e5 | 약 8.23:1 |

[WCAG 1.4.11 설명](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)은 컨트롤 식별에 필요한 시각 정보와 인접 배경의 대비 3:1을 요구한다.
호버 전후의 색끼리 3:1 차이를 만들거나 별도 호버 효과를 추가하라는 요구는 아니다. 호버 때문에 컨트롤 자체의 식별 대비가 부족해지지 않아야 한다.
이 검색 아이콘의 수정 전 호버 조합은 그 대비 기준을 충족하지 못한다. 전체 사이트의 접근성 판정과는 구분한다.

**확정·적용:** 헤더 검색 한곳의 기본 #737373은 유지하고 호버 때 기존 팔레트의 #404040으로 진해지게 한다.
사용자는 같은 색이면 호버 피드백이 없어지는 점을 지적했다. 최초의 같은 회색 유지안은 식별 대비만 해결하고 기존 색 변화 반응까지 없애므로, 반응을 유지하는 안으로 수정했다.
호버 효과가 반드시 색 변화여야 하는 것은 아니지만 이 버튼은 이미 색으로 반응을 주고 있으므로 그 방식을 보존한다. 기본 모습·크기·배치·검색 동작·입력 초점은 그대로다.
어두운 바탕의 다른 quiet 버튼에 적용 중인 흰색 호버는 이번 범위가 아니다.

[수정안 측정·캡처 기록](search-icon-feedback-comparison/measurements.json). 새 프로덕션 프론트·기존 로컬 API·Playwright 1.57.0 Linux Chromium에서 확인했다.
승인 전 같은 DOM에서 호버 색만 임시 지정한 비교 기록이다.
DS-017을 HeaderSearchBar에 적용했고 [실제 적용 기록](search-icon-implementation/measurements.json)의 한국어·영어 기본/호버 이미지 4장이 원본/승인 견본과 각각 일치했다. 이탈 시 색 복귀와 Tab 초점도 확인했다. 검색 제출은 하지 않았다.
[최초 같은 회색 유지안](search-icon-comparison/measurements.json)은 대체된 비교 기록이다. 현재 추천안이 아니다.

## 다음 확인

아이콘 그림과 클릭 영역을 구분해 검색·메뉴·닫기 22개 상태의 영역·인접 간격·키보드 초점을 확인했다.
[클릭 영역 조사와 I-Q2](ICON-TARGETS.md) · [실제 비교](icon-targets.html). 입력칸과 붙은 세 검색 실행의 영역 확대를 DS-018로 적용했다. 한·영 8장면이 승인 견본과 일치했고 가장자리·키보드 초점·긴 입력 배치를 확인했다. [적용 기록](icon-target-implementation/measurements.json). 다른 작은 메뉴·닫기는 확인한 간격이 충분해 유지한다.
태그·페이지 이동·예약·캐러셀·교과목 카드 32개 표본을 추가 실측했다. [기존 기준·남은 범위](ICON-STATES.md). 카드 화살표의 키보드 초점 표시 문제는 [I-Q3](icon-focus.html)로 비교했고 아직 미적용이다. 연구실 자료 등 미측정 사용처는 남아 있다.

문서 가로 넘침 없음, 한국어·영어 6개 검색 바 이미지 로딩·전환, 내부 링크를 확인했다.

이는 검토 문서 확인이며 검색 호버의 앱 적용 결과는 아니다.
