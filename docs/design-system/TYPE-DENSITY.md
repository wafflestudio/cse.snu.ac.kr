# 본문 읽기 밀도 — DS-016 기존 14px 유지

[현재 DS](index.html) · [현재 견본·이전 비교](type-density.html) · [역할별 타이포 기준](TYPOGRAPHY-BASELINE.md)

DS-015의 16px/32px 확대를 철회하고 **기존 14px/400/줄높이 28px**를 유지한다.
공지 상세에 추가했던 영역별 크기 클래스만 제거했다. 다른 뷰어·공유 CSS·에디터 변경은 없다.

## 유지 이유와 범위

이전 확대는 읽기 밀도의 선호 제안이었으며, 기존 14px에서 확인한 접근성 문제나 같은 역할의 불일치를 해결하는 변경은 아니었다.
사용자는 명확한 이유 없이 기존 디자인을 바꾸지 않는 기준을 제시했다. DS-016으로 이후 작업의 변경 판단에도 반영했다.
글자 크기 하나만으로 전체 접근성 적합성을 선언하는 결정은 아니다.

기존 본문의 상대 크기 h2는 21px, h3는 약 16.38px이며 줄높이는 기존 비율 2다.
작성자 지정 18px 같은 별도 크기는 유지한다. 문단·정렬도 기존 규칙을 유지하며, 문제가 확인되면 해당 사용처와 상태를 근거로 검토한다.

## 복원 확인

새 프로덕션 프론트·기존 로컬 API·Playwright 1.57.0 Linux Chromium에서 한국어·영어 1280·390px을 확인했다.
본문 이미지 4장이 원래 A와 바이트까지 일치했고 폭·높이·h2 21px·작성자 지정 18px·글 제목 20px/600도 대조했다.
인사말의 다른 뷰어는 14px를 유지했다. 조사 전용 공지는 삭제했다.
[복원 기록](type-density-restoration/measurements.json). 전체 콘텐츠·접근성 검증을 대신하지 않는다.

[기존 A/B 원자료](type-density-comparison/measurements.json)와 [DS-015 당시 확대 적용 기록](type-density-implementation/measurements.json)은 과거 비교 자료다.
현재 기준은 DS-016이며 추가 확대 적용 대상은 없다.
