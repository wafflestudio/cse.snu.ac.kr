## 확정·적용한 내용

DS-024 메인 필터 줄바꿈과 공지 태그 A는 실제 앱에 적용했다. 14장 이미지가 승인 견본과 일치했고
72개 상태·키보드 선택·편집 중 비활성을 확인했다. [적용 견본](filter-layout.html).
데스크톱 편집·관리 24개 상태도 확인하고 기존 간격의 역할을 [정리](DESKTOP-LAYOUT.md)했다.

## 남은 문제와 변경 이유

같은 태그 컴포넌트의 **영어 통합검색**은 짧은 태그용 최소 80px 열을 쓴다.
하지만 `Research & Edu`는 아이콘 포함 약 133px다. 639·640·768·1200·1280px에서 다음 `Admissions` 항목과 겹쳤다.
페이지 전체의 가로 넘침은 없어서 개별 항목 경계를 확인해야 발견되는 문제다.
DS-024는 긴 공지 태그 그룹에 한정했고, 이 짧은 그룹은 기존 배치를 그대로 두었다.

**제안:** 영어 통합검색도 승인한 A의 열 정렬 원칙을 따르되 최소 160px 열을 쓴다.
기존 160px 열 값을 재사용하면 최장 항목 약 133px와 조작 영역이 들어간다. 공지의 240px까지 넓힐 이유는 없다.
한국어 통합검색과 겹침이 없었던 뉴스의 기존 열은 유지한다. 문구·순서·색·글자·필터 동작은 바꾸지 않는다.

1280px에서는 6열 한 줄이 3열 두 줄, 390px에서는 2열 세 줄이 1열 여섯 줄이 된다.
공간을 더 차지하지만 이름을 생략하거나 글자를 줄이지 않고 기존 열 정렬을 유지한다.
이는 새로운 모든 태그의 고정 폭 규칙이 아니라 실제 언어·항목 길이에 맞춘 사용처별 적용이다.

## 비교와 한계

두 언어 × 9개 폭 × 기존/제안 = 36개 상태를 로컬 프로덕션 앱의 DOM 스타일만 변경해 비교했다.
[실측](search-grid-comparison/measurements.json). 제안 18개 상태에서 문서 넘침·같은 줄 항목 겹침이 없었다.
대표 390·768·1280px의 한·영 이미지를 제공한다. **앱 소스에는 아직 미적용**이다.
승인 후에는 통합검색 필터의 클릭·키보드 선택과 결과 연결, 다른 태그 그룹 유지 여부를 대표 표본으로 확인한다.
