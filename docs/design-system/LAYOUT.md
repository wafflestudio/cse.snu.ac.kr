## 지금의 상태

3-4 기반 아이콘의 기존 구성·승인한 첫 사용처 적용을 정리하고 3-5를 시작했다.
DS-021 연구실 자료 아이콘은 한·영 두 폭의 실제 이미지가 승인 견본과 일치했고 공통 초점도 연결됐다.
컴포넌트 전체 상태는 4단계에 남는다. 공통 틀·푸터·메인/공지 필터를 DS-022~024로 적용했다. [데스크톱 편집·관리 24개 상태](DESKTOP-LAYOUT.md)도 확인했고 역할별 기존 간격을 유지한다. 영어 통합검색 태그는 별도 비교 중이다.

## DS-023 적용 전 실측 기록

현재 프로덕션 빌드의 학부 소개를 한국어·영어 각각 320·360·390·639·640·768·1024·1199·1200·1280px에서 확인했다.
[20개 상태 기록](layout-audit/measurements.json). 320px는 조사 표본이며 제품의 최소 지원 폭을 새로 확정한 것이 아니다.

| 화면 | 기존 문서 폭 | 관찰 |
| --- | --- | --- |
| 한국어 320·360·390·639px | 뷰포트와 동일 | 이 공통 틀 표본에서 전체 가로 넘침 없음 |
| 영어 320·360·390px | 436px | 푸터 More의 긴 링크가 열 밖·화면 밖으로 나감 |
| 영어 639px | 728px | 한 줄에 더 많은 그룹이 배치돼 More가 더 오른쪽으로 넘침 |
| 두 언어 640·768·1024·1199px | 1200px | 루트 최소 폭 때문에 전체 가로 스크롤. 푸터 줄바꿈만으로 해결되지 않음 |
| 두 언어 1200·1280px | 뷰포트와 동일 | 이 표본의 현재 데스크톱 배치 유지 가능 |

중간 폭의 최소 폭 제거만 먼저 하면 본문·좌우 탐색·표·예약 구성이 충돌할 수 있다.
푸터와 구분해 헤더·본문·탐색·표/달력을 함께 비교하고 전환 범위를 결정해야 한다. 이 문제를 해결 완료로 처리하지 않는다.

DS-023 이후 아래 모바일/데스크톱 여백의 전환은 1200px이며, DS-022 푸터 줄바꿈도 1200px 미만으로 확장했다.

## DS-022 — 모바일 푸터의 긴 링크 줄바꿈 적용

**문제:** Footer 그룹의 링크에 `whitespace-nowrap`가 붙어 있어 긴 영어 항목이 고정 열을 벗어난다.
**변경 이유:** 링크 끝을 읽으려면 페이지를 가로로 움직여야 한다. 서체·크기를 줄이거나 이름을 생략할 이유보다 배치 제약을 푸는 이유가 명확하다.
**확정·적용:** 기존 모바일 범위(<640px)에서 링크가 자기 열 안에서 단어 단위로 줄바꿈하도록 허용한다. 기존 그룹 폭·순서·간격·서체·색과 데스크톱 한 줄 표시는 유지한다.
**효과:** 영어 320·360·390·639px 표본에서 문서 폭이 화면 폭과 같아졌다. 길어진 항목만 여러 줄이 되고 푸터 높이가 늘어난다.
**대가·한계:** 영어 More의 일부 항목은 2~3줄이 된다. 데스크톱과 중간 폭의 1200px 최소 폭 문제는 별도다. 임의의 긴 URL·단어를 강제로 글자마다 자르는 제안은 아니다.

[한·영 320·390·1280px 비교](layout.html)는 현재 실제 앱 적용 결과다. 승인 전에는 DOM의 white-space만 임시 변경해 비교했다.
한국어와 데스크톱 비교 이미지는 전후 동일했다. 링크 이름·목적지·그룹 순서는 바뀌지 않는다.

**적용 확인:** 새 프로덕션 빌드의 한·영 20개 상태의 배치가 승인 견본과 일치했고 대표 이미지 6장도 바이트까지 일치했다. [적용 기록](footer-implementation/measurements.json).

## DS-040 — 긴 페이지 제목

괄호 앞 줄바꿈 지점이 있는 제목은 작은 화면에서 상자 폭을 제한하고 의미 단위로 줄바꿈한다. 모바일24px·데스크톱32px와 장식용100px 공간을 유지한다. 참가자 한영3폭6장 승인안 일치·다른 제목24장 기존 동일 확인. [실제 적용](long-title.html). 긴 경로 표시는 이후 DS-041로 단계별 줄바꿈·왼쪽 텍스트 정렬을 적용했다. [실제 적용](breadcrumb.html).

## DS-041 — 경로 줄바꿈의 왼쪽 정렬

구분 화살표와 다음 이름을 한 단위로 줄바꿈하고, 긴 항목의 텍스트는 왼쪽에 정렬한다. 작은 화면에서는 제목 영역을 기존 좌우20px 안으로 제한한다. 경로 줄 간격4px·그래픽 최소100px 공간을 사용하며 기존 글자 크기·문구·링크 동작을 유지한다. 한영48상태와 대표6이미지·경로 링크 이동을 확인했다. 접근성 후속은 미재개다.
