DS-008 · 승인·앱 적용

주황 배경과 흰 글씨는 그대로 유지한다. 이번에는 입력 예시·보조 버튼 글자·입력 초점을 기존 회색 팔레트 안에서 조정한다.

현재 DS 전체현재 / 제안바뀌는 값결정과 적용현재 위치

공용 Text·TextArea·Button의 스타일을 옮긴 비교 견본이다. 앱 화면 캡처가 아니며 폼 저장·취소 기능은 연결하지 않았다. 두 칸에 직접 입력하거나 Tab 키로 이동해 볼 수 있다. 문구·크기·배치는 이번 제안의 변경 대상이 아니다.

입력한 글자·버튼 바탕·글자 크기·간격은 유지한다. 입력 예시는 입력값보다 옅게 남기되 읽을 수 있게 한다. 보조 버튼은 짙은 바탕의 주요 버튼보다 약한 강조를 유지한다.

기존 밝은 회색 #fafafa 바탕에서 제안 입력 예시의 대비는 4.54:1이다. 비활성 입력의 글자색은 유지한다. 초점은 :focus-visible을 사용한다. 텍스트 입력은 브라우저에 따라 마우스로 눌렀을 때도 표시될 수 있다. 표시가 생겨도 요소 크기와 배치는 변하지 않는다.

이 견본은 전체 접근성 검증이 아니다. 기본 입력 테두리·다른 입력 종류·검색창·어두운 바탕·링크·오류 표시는 후속 검토한다. 주황/흰 글씨의 알려진 대비 한계는 DS-007로 보류했다.

결정과 적용 · DS-008

입력 예시 #737373, 보조 버튼 글자 #525252, 입력 초점 #404040 / 2px / offset 2px를 승인하고 앱에 적용했다.

공지 입력과 예약 모달 1280·390px, 보조 버튼 기본·호버를 실제 앱에서 확인했다. 모바일 예약창의 넘침·초점 일부 잘림은 별도 배치 항목으로 남겼다. 적용 범위와 확인 한계.

이 페이지는 승인한 전후 견본을 보존한다. 현재 규칙 전체는 누적 DS에서 볼 수 있다.
