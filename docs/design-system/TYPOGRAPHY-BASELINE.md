# 타이포 기반 — 기존 역할과 예외 유지

[현재 DS](index.html) · [진행 현황](PLAN.md) · [DS-016 결정](DECISIONS.md)

DS-016에 따라 명확한 문제가 확인되지 않은 기존 타이포는 유지한다.
아래는 현재 코드와 앞선 화면 조사를 대조한 **기존 구현의 사용 기준**이다. 모든 숫자를 새 표준으로 통일하거나 기존 페이지를 재디자인하는 승인이 아니다.
본문 확대·제목 확대 검토는 종료했고, 승인한 기본 서체 연결은 유지한다.

`app.css`의 12·13·14·16·18·22·24·30px 크기 토큰과 17·20·32·64px 등 사용처별 값은 그대로 둔다.
이름·단계 수를 정리하려는 이유만으로 픽셀을 바꾸지 않는다.

## 부분 제목과 밀도의 예외

- 교과목 정보 제목은 17px/700, 졸업 사정 안내는 18px/700, 졸업생 진로·기업 묶음은 16px/700이다.
  서로 다른 화면의 정보량·위치·주변 제목이 다르다. 같은 컴포넌트의 동일 상태가 어긋났다는 증거가 없어 기존 사용처별 예외로 남긴다.
- 본문은 기존 줄높이 2와 문단 아래 10px, 양끝 정렬을 유지한다. 현재 표본의 영어 단어 간격은 관찰할 수 있지만 선호 차이를 곧바로 새 정렬 규칙의 근거로 삼지 않는다.
- 표·목록·작성자 HTML·사진을 두른 본문은 콘텐츠 구조의 영향이 있다. 기본 크기 하나로 모두 정규화하지 않는다.
- 긴 제목과 작성자·날짜의 줄바꿈, 좁은 화면 넘침은 3-5 배치와 5단계 대표 화면 검증으로 연결한다. 글자를 줄이거나 키워 배치 문제를 우회하지 않는다.

## 근거와 확인 범위

[초기 역할 조사](ROLE-AUDIT.md), `app.css`, CategoryPage, PageTitle, SelectionTitle, PeopleGrid,
Fieldset·Text, ui/Button·Tag, 공지·새 소식·세미나 상세와 기존 본문 CSS를 대조했다.
이번에 교과목 정보·졸업 사정 안내·졸업생 진로/기업 제목의 17·18·16px 사용처를 추가 대조했다.
원래 화면의 역할 차이로 보존하며 변경 테스트를 만들지 않았다.

본문 복원은 새 프로덕션 빌드에서 한국어·영어 1280·390px의 이미지·폭·높이를 원래 A와 대조했다.
[복원 기록](type-density-restoration/measurements.json). 본문 네 이미지가 일치하고 제목 20px/600과 명시적 18px도 유지됐다.
이 역할표가 전체 콘텐츠·모든 폭의 가독성이나 접근성 검증 완료를 뜻하지 않는다.

## 3-3 정리와 이후 범위

서체·기본 본문·글 제목·보조 정보와 기존 역할별 크기·행간·예외를 문서화했다.
3-3은 **기존 유지 기준 정리**로 마치고 3-4 아이콘으로 이동한다.
배치 문제는 3-5, 컴포넌트별 상세 상태는 4, 전체 회귀는 5에서 확인한다.
새 문제가 재현되면 해당 규칙만 근거와 함께 다시 검토한다.
