# 글 제목과 보조 정보 — DS-016 기존 A 유지

[현재 DS](index.html) · [현재 견본·이전 비교](post-typography.html) · [타이포 역할표](TYPOGRAPHY-BASELINE.md)

공지·새 소식·세미나 상세의 글 고유 제목은 **20px/600/줄높이 28px**를 유지한다.
공지·새 소식의 작성자·날짜·조회수는 기존 13px/400을 유지한다. T-Q3은 A로 결정했다.
24px/700 제목은 앱에 적용하지 않았으므로 제목 소스 복원은 필요 없다.

## 유지 이유

본문을 14px로 복원한다. 본문 안 기본 h2 21px와 글 고유 제목 20px는 역할과 위치가 다르다.
단순한 크기 비교만으로 고유 제목을 키울 충분한 근거로 삼지 않는다.
사용자의 기존 디자인 유지 원칙에 따라 확대 제안은 철회하고 기존 관계를 문서화한다.

제목 아래 보조 정보 13px와 세미나의 연사·장소 등 구조화된 내용 14px는 서로 다른 역할이므로 일괄 통일하지 않는다.
모바일 작성자·날짜 줄바꿈은 글자 크기 변경으로 우회하지 않고 3-5 배치 검토에서 확인한다.

[당시 확대 비교 원자료](post-title-comparison/measurements.json)는 DS-015의 16px 공지 본문을 배경으로 한 과거 자료다.
현재 본문 모습은 [DS-016 복원 기록](type-density-restoration/measurements.json)을 따른다.
새 제목 크기를 결정하거나 적용해야 할 질문은 남아 있지 않다.
