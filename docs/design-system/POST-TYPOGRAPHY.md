# 글 제목과 보조 정보의 위계 — T-Q3 제안

[현재 DS](index.html) · [실제 화면 비교](post-typography.html) · [진행 현황](PLAN.md)

**확정·적용:** DS-015의 본문 16px/400/32px는 공지 상세에 반영했고 한국어·영어 두 폭에서 승인 견본과 일치했다.
**이번 제안:** 공지·새 소식·세미나의 글 고유 제목을 24px/700으로 맞추고, 공지·새 소식의 날짜·조회수 등 보조 정보는 기존 13px/400을 기준으로 삼는다. 제목 변경은 앱 미적용이다.

## 현재 문제 → 변경 이유 → 기대 효과

세 화면의 고유 제목은 현재 20px/600/줄높이 1.4다. 공지 본문을 16px로 정하면서 본문 안 기본 h2는 24px/700이 됐다.
글 전체를 소개하는 제목이 본문 소제목보다 작고 덜 굵게 보일 수 있다. 원래도 기본 본문 h2는 21px/700이라 같은 관계가 있었다.
이는 이번 본문 변경으로 새로 생긴 기능 버그가 아니라, 제목 역할을 정리할 때 함께 판단할 시각적 관계다.

**B 추천: 고유 제목 24px/700, 줄높이 비율 1.4 유지(33.6px).**
기본 본문 소제목보다 작지 않게 하고, 글의 시작을 뚜렷하게 표시한다. 기존 text-2xl 24px와 font-bold 700을 재사용하는 안이다.
날짜·조회수·작성자는 제목을 보조하므로 기존 13px/400과 DS-010의 밝은 바탕 보조색 #737373을 유지한다.
본문을 키웠다는 이유로 모든 짧은 정보도 함께 키우지 않는다.
특정 제목 크기·굵기가 접근성 필수값이라는 주장은 아니며, 이 시각적 위계를 선택하는 디자인 제안이다.

제목 영역은 더 높아지고 긴 제목은 줄바꿈이 늘 수 있다. 이번 혼합 긴 제목은 모바일에서 두 안 모두 2줄이었지만 높이는 56→67.2px가 됐다.
기존의 절제된 제목 크기가 더 중요하면 A(20px/600)를 유지할 수 있다.
작성자가 더 큰 h1이나 크기를 직접 넣은 모든 콘텐츠보다 글 제목이 항상 클 것이라는 보장은 아니다.

## 주변 규칙과 구분

| 역할 | 값과 상태 | 이번 범위 |
| --- | --- | --- |
| 어두운 상단의 페이지 구분 이름 | 현재 데스크톱 32px / 모바일 24px / 700 | 세 상세 화면에서 유지. 모든 페이지 제목 규칙의 확정은 아님 |
| 글 고유 제목 | A 20px/600 → B 24px/700, 줄높이 1.4 | 이번 판단. 공지·새 소식·세미나 상세 3곳 |
| 작성자·날짜·조회수 | 기존 13px/400, 줄높이 1.2, #737373 | 공지·새 소식의 기존 보조 정보 기준 유지 제안 |
| 읽는 본문 | DS-015 기본 16px/400/32px | 공지만 적용 완료. 새 소식·세미나 본문은 아직 14px |
| 세미나 연사·장소·일시 등 | 현재 구조화된 정보 14px | 짧은 날짜·조회수와 동일한 역할로 치환하지 않음 |

첫 소스 범위는 `apps/web/src/routes/$locale/community/{notice,news,seminar}/$id.tsx`다.
제목의 크기·굵기만 변경하며 줄높이 비율·간격·색·문구·HTML 구조는 그대로다.
목록 행의 제목, 내비게이션, 일반 섹션 제목, 폼 라벨·입력, 에디터는 이 질문의 적용 범위가 아니다.

## 실제 비교

DS-015를 적용한 새 프로덕션 프론트와 기존 로컬 API, Playwright 1.57.0 Linux Chromium에서 확인했다.
같은 DOM에서 고유 제목의 font-size·font-weight만 바꿨다. 앱 제목 소스는 변경하지 않았다.
공지의 긴 제목은 조사 전용 한국어·영어 혼합 표본이며 확인 뒤 삭제했다. 새 소식·세미나는 기존 로컬 시드다.

| 장면 | A → B 제목 요소 높이 | 제목 줄 수 |
| --- | --- | --- |
| 공지 1280px | 28 → 33.6px | 1 → 1 |
| 공지 390px | 56 → 67.2px | 2 → 2 |
| 새 소식 1280px | 28 → 33.6px | 1 → 1 |
| 세미나 390px | 100 → 105.6px (기존 위아래 패딩 72px 포함) | 1 → 1 |

4장면 모두 제목 폭·문구·색과 본문 크기·높이를 유지했다. 제목 높이만큼 뒤의 내용이 내려간다.
[측정 기록](post-title-comparison/measurements.json). 전체 제목·영어 페이지·중간 폭의 회귀 확인은 아니다.
승인 후 실제 클래스 변경과 한국어·영어 두 폭을 대조한다.
공지 모바일의 작성자·날짜·조회수 줄바꿈은 기존 배치다. 이번에는 크기 기준을 유지하고 배치 개선은 3-5로 남긴다.

## 이번 판단

**B처럼 고유 제목을 24px/700으로 맞추고, 공지·새 소식의 보조 정보는 기존 13px/400을 유지할까?**
A는 현재 20px/600 유지다. 보조 정보는 두 안 모두 같으며 본문 16px/32px 결정도 유지한다.
이후 일반 섹션 제목·설명·본문 정렬과 다른 읽기 사용처를 검토한다. 전체 타이포를 이번 질문으로 완료하지 않는다.

## 문서 확인

Playwright 1.57.0 Linux Chromium의 1280·390px에서 누적 DS·승인 본문·제목 비교 문서의 가로 넘침 없음을 확인했다.
제목 견본의 크기·굵기, 승인 본문 줄높이, 8개 실제 비교 이미지 전환·로딩과 내부 링크를 확인했다.
문서 확인이며 제안한 제목의 앱 적용 확인은 아니다.
