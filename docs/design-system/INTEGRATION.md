# 5단계 일반 시각 통합 검증

2026-09-24. [실제 견본](integration.html). 접근성 후속은 아직 재개하지 않았다.

## 실행 범위

- 현재 소스의 프로덕션 빌드, 로컬 실제 API, 고정 Playwright1.57 컨테이너.
- 공식 read/read-mobile 프로젝트·스펙·기준 이미지 사용. 기존 캐시 빌드의 서버 기동과 로컬 API 주소만 환경에 맞췄다. 공식 globalSetup으로 로컬 DB를 리셋·시드했다. 워커4·재시도2.
- 전체읽기140개:68통과·1재시도통과·71실패. 최종 실패70개는 이미지 비교,1개는 브라우저 SIGSEGV 기동 실패(앞선2시도에서는 이미지 차이). 기능 assert 실패 없음. 전체 통과로 처리하지 않는다.
- 이미지 차이를 승인 DS·기존 차이·추가 조사로 분류 중. 목록만 워커1·재시도0으로 분리 실행하면4개 중3개 통과, 새소식 데스크톱1개 실패였다. 모바일2건은 이 실행에서 재현되지 않았다. 실행 전후 조회수가 달라졌으므로 동시성이 원인이라고 단정하지 않는다. 기존 기준 이미지는 아직 갱신하지 않았다.
- 추가 공개14장면과 관리2장면을 확보했다. 공개의영어320/390px·768px·1023/1024px, 한국어1280px와예약1023px, 관리1200px의오류/긴첨부/편집이탈을 포함한다.16장면 문서 가로폭에서 넘침 없음. 16개 PNG를 직접 검토한 결과 새 겹침·잘림이나 승인 DS와 다른 표현은 확인하지 못했다. 모든 언어·경로·데이터 조합을 검사한 것은 아니다.

## 관찰과 제한

- 1023/1024px 교과목 목록/카드와 예약3일/7일 전환은 기존 역할 구분을 유지한다.
- 영어 교과목 카드에서 HTML 태그가 설명 글자로 표시되는 현상은 기존 Q-14다. 기능·콘텐츠 표시 조사에 남기며 수정하지 않았다.
- 영어 페이지에서도 기존 한국어 관리 필드명·일부 필터명·시드 콘텐츠가 남는다. 이번 검증을 번역 전수 완료로 해석하지 않는다.
- 확인창 전체 페이지 캡처는 현재 뷰포트 밖에 오버레이가 없는 것처럼 보이므로 실제 확인용은 뷰포트로 저장했다.
- 임시 캡처에서 처음 사용한 공지 오류 문구 선택자/파일 입력 대상과 태그 토글을 바로잡고, 실제 제목 오류·첨부파일명·태그 선택 상태를 확인한 이미지를 저장했다. 앱 수정으로 해결한 문제가 아니다.
- SunEditor 내부·CSP·Sonner 내부·기능 버그는 작업 범위에서 제외했다. 초점·키보드 후속은 마지막에 별도로 검증한다.

- 짧은 한국어 인사말 시드에서는 오른쪽 메뉴가 푸터 바탕까지 내려오지만 텍스트와 충돌하지 않는다. 출발점에도 같은 배치 코드가 존재하므로 이번 DS 회귀로 분류하지 않는다.
