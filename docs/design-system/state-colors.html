현재 DS 전체제안 이유직접 보기실제 화면 비교이번 판단

왜 바꾸고, 무엇은 유지하는가

검색 입력의 현재 문제: 키보드로 이동해도 초점 외곽선이 없다. 작은 커서 외에 현재 입력 위치를 두드러지게 표시할 필요가 있다.

변경 이유: DS-008과 같은 2px 외곽선·2px 간격을 검색 바에 적용한다. 밝은 구역은 #404040, 어두운 헤더는 흰색으로 표시해 각각의 바탕에서 눈에 띄게 한다.

기대 효과와 범위: 입력 위치를 쉽게 찾고 기존 크기·배치를 유지한다. 입력에 초점이 있을 때만 표시하고, 검색 버튼으로 이동하면 기존 버튼 초점이 남는다. 검색 동작과 기본 배경을 바꾸는 제안은 아니다.

오류 색을 유지하는 이유: 기존 red-600은 흰색·#fafafa에서 약 4.77:1·4.57:1로 일반 글자 대비 기준 4.5:1을 넘는다. 이 바탕의 오류 문장에는 기존 빨강을 유지하고 사용 기준을 명확히 한다.

#f5f5f5에서는 약 4.38:1이므로 모든 회색·어두운 면으로 확대하지 않는다. 수치는 Chromium의 sRGB 변환값 기준이며 전체 접근성 충족을 뜻하지 않는다.

02. 실제 검색 입력의 초점 전후

두 안 모두 입력에 키보드 초점을 둔 상태다. 제안은 같은 앱 화면의 검색 바 외곽선만 바꿨다.

표시할 안

표시한 원본 이미지 · 측정 기록

입력 바 주변 10px를 포함한 부분 캡처다. 5장면 모두 전후 크기가 같았다. 앱의 초점 규칙 구현·전체 검증은 아직 하지 않았다.

이번 판단 · C-Q6

오류는 밝은 바탕에서 기존 빨강을 유지하고, 검색 입력에는 이 초점 외곽선을 적용할까?

밝은 구역 #404040 / 어두운 헤더 흰색, 두 곳 모두 2px·간격 2px다. 입력에 초점이 있을 때만 표시한다.

기본 입력 테두리·나머지 컨트롤 상태는 후속 검토에 남는다. 오류 검증 로직·에디터·Sonner는 변경하지 않는다.
