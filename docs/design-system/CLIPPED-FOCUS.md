# 이미지 안내창 — DS-033·034 적용

[실제 견본](clipped-focus.html) · [누적 DS](index.html) · [계획](PLAN.md)

2026-09-24. 사용자 “둘 다 좋아”로 **CF-Q1·CF-Q2를 승인했고 DS-033·034로 적용·대표 검증했다**. 아래 비교는 변경 이유와 승인 전 기록이다. ImageModal의 ‘다시 보지 않기’ 초점 연결은 기존 DS-020 반복 적용으로 완료했고, 아래 하단 두 버튼과 구분한다.

## 먼저 완료한 것

- DS-031 B: 첨부 파일명은520×30px 행에서 한 줄 말줄임. DS-032 삭제 원은 기본500/호버700. 승인 견본의 파일명 영역·두 아이콘이 실제 적용과 동일하다. [파일 적용](file-controls.html).
- DS-020을 Pagination 숫자·활성 화살표, 공지 제목, 앞뒤 글, CategoryGrid 카드, ui/Dropdown 트리거, ImageModal 체크 라벨에 연결했다.
- [실제 탐색 표본](navigation-focus-implementation/measurements.json): 페이지2 이동·제목 Enter 이동, 앞뒤 글 초점, 삭제 확인창 취소 초점/Escape, 카테고리2곳, 졸업생 진로 드롭다운 열기/방향키/Escape, 이미지 팝업 체크 Space/해제·Escape. 삭제 확인 동작은 실행하지 않았다.
- CategoryGrid의 실제 사용처는 모두 dark다. light 분기는 소스 연결만 했고 실제 사용처 렌더를 검증한 것으로 표시하지 않는다. 확인창 취소·확인은 기존 공용 Button 초점을 재사용한다.

## CF-Q1 — 이미지 팝업 하단 버튼의 초점 위치

변경 전 ImageModal의 닫기/자세히 보기 버튼은 `focus:outline-none`이며 별도 초점 표시가 없다. 조상은 모서리4px·overflow-hidden으로 이미지를 자른다. DS-020 바깥2px 간격·2px 선을 그대로 대입하면 버튼 가장자리의 선도 잘린다.

**확정·적용:** 이 두 버튼만 가장자리에서 안쪽2px를 띄운2px 실선으로 표시한다(outline-offset:-4px). 기존 neutral-700을 쓰며 버튼 크기·이미지 크기·주황·흰 글자를 유지한다. 키보드 초점 때만 나타나며 전역 초점 규칙이나 텍스트 입력은 바꾸지 않는다. 통일성은 선의 두께·색·키보드 표시 조건으로 유지하고 잘리는 사용처에서 위치만 예외로 둔다.

바깥선을 고수하려면 버튼 주변에 공간을 마련하거나 이미지 잘림 구조를 바꿔야 한다. 현재 배치를 유지하는 안쪽 표시를 추천한다. 두 버튼·한 개 버튼·한영 좁은 폭·강제 색상 모드를 실제 코드에서 확인했다. 제안 단계의 한영 견본은 DOM에 직접 스타일을 대입한 것이며 실제 앱 적용과 구분한다.

## CF-Q2 — 닫기 버튼 색

기존 기본 글자500/바탕100, 호버 글자400/바탕50이다. 포인터를 올리면 글자가 더 흐려진다.

**확정·적용:** 기본 글자600(#525252)/바탕100(#f5f5f5), 호버 글자600 유지/바탕200(#e5e5e5). 이미 쓰는 보조 버튼의 역할색을 적용한다. 호버 시 바탕색이 변해 피드백을 유지하면서 닫기 문구가 흐려지지 않는다. 기본 글자는 조금 더 진해지고 호버 바탕도 진해진다. 눌림은 기존 바탕200에 글자600을 유지하는 것으로 맞춘다.

닫기 버튼의 기존 크기·15px 글자·문구는 유지한다. 주황 자세히 보기의 기본·호버·눌림색은 이 질문으로 바꾸지 않는다. 위험 행동색을 정하는 작업도 아니다.

## 다음 범위와 검증 한계

- 메인 NewsCard의 바깥 초점도 캐러셀에 잘린다. 단순 안쪽선은 상단 이미지에 가려지는 것을 실제 DOM 비교에서 확인했다. 해당 시안은 채택하지 않는다. 사진 위 대비와 선의 겹침 순서를 함께 처리할 필요가 있어 후속 비교로 남긴다. [시도 기록](clipped-focus-comparison/measurements.json).
- form Dropdown의 기존 닫힌 옵션 키보드 문제는 Q-15로 유지한다. ui Dropdown은 listbox와 aria-activedescendant·활성 배경으로 이동 항목을 표시한다. 둘의 탐색 로직을 합치거나 모든 옵션에 이번 안쪽 초점을 일괄 적용하지 않는다.
- 이미지 팝업은 로컬 API에서 임시 생성 후 삭제했다. 제안은 하단 컨트롤을 비교하며 실제 행사 이미지를 검토한 것이 아니다. [측정](clipped-focus-comparison/measurements.json).

## 실제 적용·검증

- 기존 focus-ring을 사용하고 이 두 버튼에만 offset:-4px를 연결했다. 강제 색상 모드의 실제 outline도 유지된다. 버튼크기46px 높이, 한영320/1280px 가로 넘침 없음.
- 기본 글자#525252/바탕#f5f5f5, 호버·눌림 바탕#e5e5e5·글자유지, 포인터 이탈을 확인했다. Tab으로 두 버튼 이동, Enter 닫기, 단일닫기·Escape를 확인했다. 외부링크는 열지 않았다.
- [실제 측정](image-modal-implementation/measurements.json), [이미지 대조](image-modal-implementation/image-comparison.json). 승인 전 색 견본은 전환 중 캡처되어 바탕 픽셀이 각각247/234였으며, 실제 최종색은 승인된245/229다. 글자·초점의 일부 렌더 차이도 있어 전체 픽셀 일치로 표현하지 않는다. 한국어 자세히 보기 영역은 동일하다.
- 로컬 임시 이미지 팝업을 생성·단일버튼으로 변경 후 삭제했다. 저장·닫기·외부링크 로직은 수정하지 않았다.
