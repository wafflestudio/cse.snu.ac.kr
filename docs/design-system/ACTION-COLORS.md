# 주요 실행의 색 — DS-014 확정·적용

[현재 DS](index.html) · [실제 화면 비교](action-colors.html) · [진행 현황](PLAN.md)

**DS-014로 값·호버·첫 적용 11곳을 확정했고 앱에 반영했다.** 아래 제안 이유와 승인 전 비교를 보존한다. 실제 적용 확인은 문서 끝에 구분한다.

## 현재 문제 → 변경 이유 → 기대 효과

같은 추가 행동인데 교수·직원·새 소식은 짙은 회색, 연구실·장학금·시설 등은 주황이다.
저장하기는 짙은 회색이고 예약하기는 주황이다. 현재 값만으로는 이 차이가 어떤 역할 차이인지 설명하기 어렵다.
DS-004에서는 일반적인 주요 실행에 짙은 중립색을 쓰기로 했지만 구체적인 값과 적용은 남겨뒀다.

기존 저장 버튼의 **#404040 바탕 + 흰 글자**, **호버 #737373 + 흰 글자**를 재사용하자.
새 회색을 늘리지 않고 이미 익숙한 저장 버튼과 추가·예약 버튼을 연결할 수 있다.
선택·그래픽의 주황은 유지하므로 작업을 시작하거나 완료하는 행동과 선택된 정보를 색 역할로 구분하기 쉬워진다.
이는 앞서 정한 역할 방향을 구체화하는 디자인 제안이다. 특정 회색이나 호버 농도가 접근성 필수값인 것은 아니다.
주황을 사용하는 면의 #ff6914와 흰 글씨 유지 결정(DS-007)은 그대로다.

| 상태 | 제안 | 근거·한계 |

이 색은 밝은 배경의 일반 주요 실행을 위한 기본값 제안이다.
위험 행동·어두운 배경·텍스트형 버튼은 역할과 배경을 따로 검토한다.
크기·문구·모서리·간격·클릭 동작은 이번 변경 대상이 아니다.

## 승인 전 비교와 확인 범위

`686fd92c`의 프로덕션 프론트와 기존 로컬 API, Playwright 1.57.0 Linux Chromium을 사용한다.
한국어 연구실 추가 1280px, 예약 열기 1280·390px, 예약창의 비활성 제출 1280px을 비교한다.
제안은 같은 DOM에서 배경 클래스를 기존 neutral과 같게 바꾼 캡처이며 앱 구현 결과가 아니다.
기본·호버 색, 버튼의 크기·글자색·불투명도 유지를 대조한다. 예약 제출은 하지 않는다.
[측정 기록](action-comparison/measurements.json).

승인 전에는 나머지 사용처와 영어를 소스로만 조사했다. 이후 변경된 빌드의 적용 확인은 문서 끝에 기록했다. 전체 회귀와 접근성 검증은 별도다.
기존 모바일 예약 배치 문제 Q-10은 이번 색 변경으로 해결하지 않는다.

## 색 검토의 남은 범위

오류 글자까지 DS-013으로 확정했고, 이번 C-Q7이 주요 실행의 값·첫 적용 범위를 잇는다.
입력 기본 경계, 선택·비활성·누름·초점의 컴포넌트별 조합은 아직 미확정이다.
각 컴포넌트의 형태·바탕과 함께 4단계에서 검토하고, 3-2를 마칠 때 이 경계를 명시한다.
색 검토 뒤에는 3-3 타이포 위계로 이동한다. 타이포 위계·아이콘·레이아웃은 아직 시작하지 않았다.

## 검토 문서 확인

Playwright 1.57.0 Linux Chromium의 1280·390px에서 누적 DS·오류 기준·이번 비교 문서를 확인했다.
8개 비교 이미지 전환·로딩, 제안 견본의 기본·호버 색, 문서 내부 링크와 가로 넘침 없음을 확인했다.
이는 비교 문서 확인이며 앱 적용 검증을 대신하지 않는다.

## DS-014 앱 적용 확인

새 프론트 빌드에서 한국어 대표 4장면이 승인안과 바이트까지 일치했다.
관리의 9개 사용처는 한국어·영어 데스크톱에서 기본·호버·기존 키보드 초점을 확인했다.
교과목은 학부·대학원, 장학금은 학부를 확인했다. 대학원 장학 페이지는 두 언어에서 404라 렌더 확인이 남는다.
예약 열기는 두 언어 1280·390px, 비활성 제출은 한국어 1280px·영어 1280·390px에서 확인했다.
[적용 측정 기록](action-implementation/measurements.json). 28개 확인 기록과 대학원 장학 404 기록 2개다.
기존 로컬 API를 사용한 탐색 확인이며 전체 회귀가 아니다. 제출·기능 로직 변경은 없다.
3-2 기반 색 검토를 정리했고, 입력 경계·컴포넌트별 상태 조합은 4단계에서 이어간다. 다음은 [본문 읽기 밀도 T-Q2](type-density.html)다.
