DS-020은 초점의 2px 선/2px 간격과 배경별 색을 확정하고 대표 네 사용처에 적용·확인했다.

## 문제 → 이유 → 제안

연구실 목록의 PDF·영상 링크는 상시 보이는 글자 없이 아이콘만으로 자료가 있음을 알린다.
기본 neutral-400(#a3a3a3)은 흰색에서 약 2.52:1, 모바일 교대 배경 #fafafa에서 약 2.42:1이다.
따라서 필수 시각 단서인 그림이 배경과 충분히 구별되지 않는다. 장식 그림의 색 차이나 단순한 취향 문제가 아니다.

[WCAG 1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)은 조작 대상을 식별하는 필수 시각 정보에 인접 색 대비 3:1을 요구한다.
이 링크는 그림이 식별 단서이므로 이 기준을 적용했다. 호버한 뒤 진해지는 것만으로 기본 상태의 낮은 대비가 해결되지는 않는다.

**추천: 기본만 neutral-500(#737373)으로 한 단계 진하게 한다.** 기존 중립색 단계이며 흰색에서 약 4.74:1, #fafafa에서 약 4.54:1이다.
호버 neutral-800(#262626)은 유지해 기본→호버의 색 변화도 보존한다. 밝은 면에서 쓰는 일반 보조 아이콘의 역할과 연결하되 모든 아이콘을 일괄 재색칠하지 않는다.
주황·아이콘 종류·선 굵기·크기·정렬·링크 동작은 유지한다. 회색 #a3a3a3 자체를 전역에서 없애는 결정이 아니다.

| 대상 | 기존 | 추천 | 유지할 내용 |
| --- | --- | --- | --- |
| PDF 자료 | 기본 #a3a3a3 → 호버 #262626 | 기본 #737373 → 호버 #262626 | FileText 20×20px / 선 1.5 |
| 영상 자료 | 기본 #a3a3a3 → 호버 #262626 | 기본 #737373 → 호버 #262626 | 기존 YouTube 도형 18×12px / 링크 18×20px |

기존 유지도 비교에 함께 남겼지만 식별 대비 부족이 남으므로 추천하지 않는다. 새 중간 회색을 추가하거나 20px 그림을 확대할 이유는 확인되지 않았다.
승인 후 두 자료 링크에는 이미 확정한 DS-020의 밝은 면 초점 규칙도 연결한다. 색 변경과 별도의 새 초점 선택을 다시 요청하지 않는다.

## 실제 조사 범위와 한계

- 기존 로컬 시드에는 자료가 없어, PDF·영상이 있는 조사용 연구실을 로컬 API로 생성했다. 실제 앱 목록을 한국어·영어 1280·390px에서 확인하고 조사용 항목은 삭제했다. 운영 데이터나 서버는 사용하지 않았다.
- [측정 기록](lab-icons-comparison/measurements.json): 기본 색·배경·링크 좌표·호버 복귀·키보드 초점 확인. 실제 렌더에서 그림의 기본 색만 임시 지정한 비교이며 앱 소스는 미변경이다.
- PDF 링크는 20×20px, 영상 링크는 18×20px, 두 링크 사이 간격은 12px다. 두 작은 대상의 중심 거리는 31px로, 중심에 놓인 지름 24px 원끼리 겹치지 않는다. 작은 아이콘이라는 이유만으로 일괄 확대하지 않는다. [2.5.8의 간격 예외](https://www.w3.org/WAI/WCAG22/Understanding/target-size-minimum.html).
- 네 표본 모두 색 제안 전후 링크 위치·크기가 같다. 기존 호버 #262626과 키보드 도달·브라우저 초점 표시를 확인했다. 외부 자료를 실행하거나 다운로드하지 않았다.
- 실제 자료의 여러 길이·데이터 조합, 모든 사용처·브라우저의 적합성을 선언하지 않는다. 복합 폼과 파일 삭제 등의 상태는 4단계다.

## 이번 판단

**연구실 PDF·영상 링크의 기본 색을 #737373으로 진하게 하고, 기존 호버 #262626과 크기·배치를 유지할까?**

검토 문서는 1280·390px에서 가로 넘침·내부 링크·네 장면 이미지 전환을 확인했다. 누적 DS와 공통 초점 견본도 함께 확인했다.
