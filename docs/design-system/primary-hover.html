기본 주황과 흰 글씨는 유지

기본 #ff6914 + 흰 글씨는 이미 정한 그대로다. 버튼 크기·문구·모서리도 유지한다. 이번 비교는 포인터를 올렸을 때의 바탕색 하나다.

현재: 공용 주황 버튼에는 호버 배경색이 없어, 포인터를 올려도 기본색과 같다. 추천: 기존 주황 태그의 호버에 쓰는 main-orange-dark · #e65817을 연결한다. 포인터가 떠나면 기존 주황으로 돌아온다.
