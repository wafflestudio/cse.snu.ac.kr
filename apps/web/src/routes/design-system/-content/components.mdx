같은 역할의 요소는 형태와 상태 표현을 공유합니다. 채움, 테두리, 글자색의 차이로 강조와 선택을 구분합니다.

## 높이

한 줄에 놓이는 컨트롤은 높이가 같아야 합니다. 세 단계이고, 값은 **바닥값**입니다 — 글자가 두 줄이 되면 그만큼 자랍니다.

<ControlHeights />

테두리는 바닥값 **안**에 들어갑니다. 테두리가 있고 없고로 높이가 갈리지 않습니다.

## 버튼

채움과 테두리, 글자색으로 행동의 강조 수준을 구분합니다.

<ButtonDemo />

주황색 채움은 추가·재시도처럼 눈에 띄어야 하는 행동에, 짙은 회색은 저장·확인에 사용합니다. 함께 놓이는 보조 행동은 연한 테두리로 구분하고, 텍스트형은 배경 없이 문구만 남깁니다.

### 배경에 따른 대비

텍스트형은 밝은 검색창과 어두운 메뉴에, 흰색 헤더형은 어두운 탐색 영역에 쓰입니다. 현재 텍스트형의 흰색 호버 상태는 밝은 배경에서 대비 보완이 필요합니다.

## 태그

둥근 윤곽과 주황색으로 짧은 분류 이름을 본문과 구분합니다.

<TagDemo />

윤곽형은 흰 바탕에 주황색 글자와 선을, 채움형은 주황색 바탕에 흰 글자를 사용합니다. 제거할 수 있는 조건에는 이름 오른쪽에 닫기 아이콘을 붙입니다.

## 체크박스와 라디오

사각 체크박스는 복수 선택을, 원형 라디오는 단일 선택을 나타냅니다.

<SelectionDemo />

체크박스는 중립색 체크 표시로, 라디오는 주황색 중심점으로 선택을 드러냅니다. 선택 표시와 이름을 가까이 두고, 선택할 수 없는 항목은 옅게 표시합니다.

## 드롭다운

현재 값과 아래쪽 화살표를 얇은 테두리 안에 함께 놓습니다.

<MenuDemo />

펼친 목록은 선택 영역과 같은 너비로 이어집니다. 선택한 값은 주황색 글자로, 초점이 놓인 행은 밝은 회색 바탕으로 구분합니다.

여러 선택지를 한눈에 비교해야 한다면 라디오를 사용합니다. 드롭다운은 현재 값에 집중하면서 공간을 아껴야 할 때 적합합니다.

## 날짜 선택

일정한 격자 안에서 오늘과 선택한 날짜를 서로 다른 표시로 드러냅니다.

<DateDemo />

오늘은 주황색 글자로, 선택한 날짜는 사각 테두리와 굵은 글자로 표시합니다. 연월은 굵게, 요일은 작게 두어 달력의 읽는 순서를 만듭니다.

## 페이지 이동

현재 페이지를 주황색 글자와 밑줄, 굵기로 표시합니다.

<PaginationDemo />

숫자는 일정한 간격으로 정렬하고 이동 화살표는 양 끝에 둡니다. 넓은 화면에서는 최대 10개, 모바일에서는 최대 5개의 번호를 보여줍니다. 이동할 수 없는 방향은 옅은 회색으로 구분합니다.

## 첨부 자료

얇은 테두리와 클립 모티프로 첨부 자료를 본문에서 구분합니다.

<AttachmentDemo />

파일명과 크기를 한 행에 나란히 놓고, 클립은 테두리에 걸쳐 배치합니다. 긴 파일명이 크기 표시를 밀어내지 않게 하며 여러 파일은 행을 나누어 정렬합니다.

## 다이얼로그

밝은 회색 바탕의 위아래에 주황색 선을 두어 집중할 영역을 구분합니다.

<DialogDemo />

제목, 설명, 행동 버튼을 세로로 정렬하고 닫기 아이콘은 오른쪽 위에 둡니다. 실제 화면에서는 주변을 반투명한 어둠으로 낮춰 다이얼로그와 배경의 층위를 구분합니다.

## 콘텐츠 입력

한 줄 입력과 여러 줄 입력에 같은 테두리와 레이블 규칙을 적용합니다.

<FieldDemo />

레이블은 입력란 위에 두고, 입력 예시는 옅은 글자로 구분합니다. 필수 표시는 레이블 옆에, 오류 설명은 입력란 가까이에 배치합니다.

### 한글과 영문

현재 편집 중인 언어는 굵은 글자와 밑줄로 표시합니다. 두 언어에서 레이블과 입력란의 배치를 유지합니다.

## 파일 첨부

파일 선택 버튼 아래에 선택한 자료를 행으로 나열합니다.

<FileDemo />

목록은 밝은 회색 바탕에 놓고 점선으로 행을 구분합니다. 파일명은 왼쪽, 제거 아이콘은 오른쪽에 정렬해 이름의 길이가 달라도 같은 위치에서 찾을 수 있게 합니다.
