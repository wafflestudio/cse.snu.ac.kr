탐색과 제목은 어두운 영역에, 본문은 밝은 영역에 놓아 위치를 파악하는 일과 내용을 읽는 일을 구분합니다. 가로 기준은 한 곳에서 나오고, 층마다 다시 정하지 않습니다.

## 가로

화면 가장자리에서 본문까지는 **데스크톱 100px, 모바일 20px** 입니다. 헤더·제목·본문·푸터가 모두 같은 선에서 시작합니다.

오른쪽 360px 은 보조 탐색의 자리입니다. **보조 탐색이 있는 페이지에만 비웁니다** — 없는 페이지에서 비워두면 넓은 화면에서 내용이 그만큼 한쪽으로 치우칩니다.

이 자리를 비우는 건 본문뿐입니다. 헤더와 푸터는 보조 탐색 **위를 지나가는 띠**라 오른쪽도 가장자리까지 갑니다. 왼쪽 선만 본문과 공유합니다.

## 폭

레이아웃은 둘입니다. 그 사이에 태블릿용을 따로 두지 않고, 모바일 쪽이 넓은 화면까지 늘어납니다.

| 폭 | 레이아웃 | 본문 |
| --- | --- | --- |
| ~1023 | 모바일 | 최대 640, 가운데 |
| 1024~1279 | 데스크톱 · 보조 탐색 숨김 | 724부터 |
| 1280~1759 | 데스크톱 · 보조 탐색 | 720부터 |
| 1760~ | 위와 같음 | 1200에서 멈춤 |

보조 탐색이 없는 페이지는 그 자리를 본문이 쓰므로 1600에서 1200에 닿습니다.

1200을 넘기면 남는 공간을 좌우로 나눕니다. 이때 **배경은 자르지 않습니다** — 흰 면과 어두운 띠는 화면 끝까지 가고 안쪽 내용만 움직입니다.

## 읽는 글

본문 칸과 읽는 글의 폭은 다릅니다. 1200은 목록·표·카드가 쓰는 폭이고, 문단이 이어지는 글은 **720에서 멈춥니다**. 한 줄이 75자 근처입니다.

## 열 간격

두 배씩 셋입니다.

| 간격 | 쓰는 곳 |
| --- | --- |
| `16` | 촘촘한 선택 목록·표 |
| `32` | 카드 격자 |
| `64` | 작은 정사각 카드 |

## 세로

| 자리 | 데스크톱 | 모바일 |
| --- | --- | --- |
| 섹션 사이 | 88 | 64 |
| 페이지 아래 | 150 | 64 |

**여백은 부모가 갖습니다.** 마지막 요소가 자기 아래 여백을 들고 있으면 같은 값을 줘도 페이지마다 결과가 달라집니다.

## 작은 화면

주 메뉴는 접고 여러 열의 정보는 읽는 순서대로 쌓습니다. 입력란과 버튼은 문구가 잘리지 않게 배치하고, 표처럼 비교가 중요한 요소는 내부에서 가로 이동할 수 있게 합니다.
